# A Little World for Her — هدية عيد ميلاد رقمية

موقع رومانسي بسيط، يعمل على الموبايل والكمبيوتر، بدون backend وبدون ميزانية.

## تشغيله محليًا
1. فك ضغط الملف.
2. افتح `index.html` بالمتصفح.
3. عدّل النصوص في `index.html`، والصور في `script.js`.

لأفضل تجربة تطوير، افتح المجلد في VS Code واستخدم إضافة Live Server.

## تخصيصه قبل الإرسال
- غيّر رسالة عيد الميلاد في `index.html` إلى كلماتك أنت.
- أضف الصور داخل `assets/photos/`.
- افتح `script.js` وأضف الصور إلى `CONFIG.photos` مثل:
  ```js
  photos: [
    { src: "assets/photos/memory-1.jpg", caption: "أول ذكرى", note: "كنت مبسوط كثير بهداك اليوم." },
    { src: "assets/photos/memory-2.jpg", caption: "ضحكتك", note: "كل ما أتذكر هاللحظة ببتسم." }
  ]
  ```
- سجّل رسالة صوتية قصيرة، واحفظها باسم `voice-message.mp3` داخل `assets/audio/`.
- بدّل أمثلة الـ timeline في `index.html` بذكرياتكم الحقيقية.
- جرّب الموقع من شاشة موبايل قبل نشره.

## نشر مجاني
### GitHub Pages
1. أنشئ repository جديد على GitHub.
2. ارفع الملفات والمجلدات الموجودة في هذا المشروع.
3. من Settings → Pages، اختر النشر من الفرع الرئيسي (`main`) ومجلد الجذر (`/root`).
4. انتظر ظهور رابط الموقع، وافتحه من هاتفك للتأكد.

### بديل
يمكن نشر المجلد نفسه على Vercel كـ static site. لا تحتاج قاعدة بيانات أو API.

## الخصوصية
- لا تضع كلمات مرور أو بيانات شخصية حساسة في الموقع.
- تذكّر أن أي صورة أو رسالة تضيفها للموقع المنشور قد يستطيع من يملك الرابط الوصول إليها.
- استخدم صورًا ورسائل تشعر بالراحة في مشاركتها، ويمكنك جعل المستودع خاصًا مع الانتباه أن إعدادات الاستضافة والرابط العام قد تختلف.
